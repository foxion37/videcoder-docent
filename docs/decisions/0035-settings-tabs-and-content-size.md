# 0035 — 설정창은 탭으로 나누고 모양 탭에서 본문 글자 크기를 정한다

Date: 2026-09-26
Status: Accepted

## Context

설정창에 모델·설명 모드·자동 설명·공유·테마가 한 줄로 쌓이면서 길어졌다. 테마 같은 모양 설정과 설명 방식 설정이 섞여 있어 찾기 어렵다. 또 화면 글자는 14px로 통일돼 있는데, 사용자마다 읽기 편한 크기가 다르다. 작업 카드 제목은 16px로 두었다가 본문과 같은 14px로 통일했다.

후보: A 한 줄 구성 유지, 글자 크기만 추가 / B 탭으로 나누고 모양 탭에 글자 크기를 둔다.

## Decision

1. **B. 탭 구성: 모양 / 설명 / 모델 / 연결.** 학습 프로필은 탭 위에 그대로 둔다. 모양 탭에 글자 크기와 테마가 있다.
2. **글자 크기는 px 숫자로 정한다.** 12에서 20px, 기본 14px. `--content-size` 변수 하나로 설명 본문(.markdown), 앱 기본 글자, 질문 말풍선, 작업 내용 요약이 같이 움직인다. 제목·버튼 같은 고정 크기 요소는 따라가지 않는다. 값은 기기(localStorage)에 저장하고 서버 저장소에 쓰지 않는다.
3. **작업 카드 제목도 본문 14px를 따른다.** 작은 창 카드 제목과 같은 크기를 유지한다(디자인 검사 규칙: 두 제목이 같고 14px 이상).
4. 글자 굵기와 여백 비율 규칙(디자인 검사)은 글자 크기 설정과 무관하게 유지된다.

## Consequences

- (+) 모양을 바꾸려고 설명 설정을 지나가지 않는다.
- (+) 비개발자 사용자가 읽기 편한 크기를 직접 정한다.
- (−) 글자 크기를 키우면 고정 크기 제목과의 비율이 줄어든다. 디자인 검사는 기본값(14px) 기준으로 돈다.
- 영향 범위: `app/index.html`, `app/markdown.css`, `scripts/check-design.mjs`, `docs/design-check.md`
