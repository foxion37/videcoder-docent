# 0020 — 배운 내용 다시보기는 단어 중심 용어 사전

Date: 2026-09-23
Status: Accepted. ADR 0008의 "자주 묻는 것" 순위·질문 종류 통계와 ADR 0017의 개념 카드 중심 다시보기를 대체한다.

## Context

다시보기 화면은 개념 카드(이해 상태, 이전 설명 전문, 수정 이력), 규칙으로 뽑은 용어, 자주 묻는 질문, 질문 종류 막대를 모두 보여 줬다. 개념 이름은 "배포 비밀값 설정 방식 비교"처럼 문장이라 사전처럼 찾기 어려웠고, `용어(풀이)` 규칙 추출은 "가짜(합성)" 같은 잡음이 많았다. 사용자는 PRD, staging, Doppler, config, token처럼 단어 중심으로 보고, 필요하면 그 단어가 나온 대화를 한 줄 링크로, 코드는 핵심만 보다가 눌러서 확인하기를 원했다.

## Decision

1. **문답마다 핵심 단어를 저장한다.** 학습 분류 호출의 출력에 `keywords:[{term, gloss}]`(최대 5개)를 추가한다. 추가 모델 호출은 없다. gloss는 그 문답의 상황이 아니라 단어 자체의 뜻이다. 형식이 잘못된 항목만 버리고 분류 결과는 유지한다.
2. **옛 문답은 요청할 때만 정리한다.** 단어가 없는 문답이 있으면 화면에 개수와 "용어 정리" 버튼을 보인다. 누르면 최근 30개를 모델 호출 한 번으로 정리한다. 모델이 빠뜨린 문답은 단어 없음으로 기록해 반복 호출을 막는다. 옛 `questions.jsonl`은 고치지 않고 단어만 `learning.json`에 따로 둔다.
3. **화면은 사전.** 검색과 정렬(자주 나온 순, 최근 순, 가나다순). 항목은 단어와 한 줄 뜻, 등장 횟수. 펼치면 코드 핵심(첫 코드 블록 앞 4줄, 눌러서 전체)과 관련 대화 링크(답의 결론 한 줄, 최근 6개)를 보여 주고, 링크를 누르면 그 답과 세션 열기가 나온다.
4. **이해 상태 편집은 유지하되 접는다.** ADR 0014의 사용자 피드백 경로는 그대로이고 화면 아래 "이해 상태 기록"에 둔다.
5. **자주 묻는 질문 순위와 질문 종류 통계는 없앤다.** `/api/stats`를 제거한다.
6. 답 속 용어 링크용 `/api/glossary`는 저장된 단어를 먼저 쓰고 기존 규칙 용어를 보조로 합친다.

## Consequences

- 사전 품질은 분류 모델의 단어 선택에 달려 있다. 같은 단어의 표기가 다르면 다른 항목이 될 수 있다(대소문자는 합친다).
- 옛 기록 정리는 사용자가 누를 때 모델 비용이 든다.
- 영향 범위: `app/wiki.mjs`(신규), `app/learning.mjs`, `app/store.mjs`, `app/review.mjs`, `app/server.mjs`, `app/index.html`, `tests/wiki.test.mjs`, `docs/architecture.md`, `README.md`
