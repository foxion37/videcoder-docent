# 0008 — 복습: 용어집과 자주 묻는 것은 문답 기억의 집계

Date: 2026-09-22
Status: Accepted

## Context

ADR 0006 이 `~/.docent/questions.jsonl` 에 문답을 남기면서 "용어집·FAQ 는 이 파일 위의 집계"라고 미뤄 뒀다. 도슨트 답은 규칙상 개발 용어를 처음 쓸 때 `용어(풀이)` 로 푼다(prompt/docent.md 말투 절). 이 패턴이 곧 용어집 재료이고, 각 문답의 `kind` 가 통계 재료다. 바이브코더가 같은 용어·같은 질문을 반복하는 것이 관찰됐으므로, 다시 묻지 않고 돌아볼 화면이 필요하다.

## Decision

1. **용어는 답을 저장하는 순간 뽑아 레코드에 넣는다.** `/api/ask` 가 답 `raw` 에서 `단어(한국어 풀이)` 패턴을 규칙으로 추출하고, Jev 가 있으면 후보마다 "앞 단어의 뜻 풀이인가" bool 판정으로 거른다(0.5 미만 탈락). 결과는 레코드의 `terms: [{term, gloss}]` 와 `termsBy: "jev" | "rule"`. 규칙만으로도 동작하고, Jev 는 정밀도만 올린다(ADR 0006 역할 분담 유지).
2. **저장값을 믿는 건 Jev 가 거른 경우(`termsBy: "jev"`)뿐.** 규칙만으로 뽑은 레코드와 `terms` 가 없는 옛 레코드는 집계할 때 `raw` 에서 다시 뽑는다. 규칙을 고치면 옛 기록에도 바로 반영되고, 파일은 append 전용으로 남는다.
3. **집계는 서버가 요청마다 파일을 읽어 계산한다.** 캐시·인덱스 없음. 문답 수천 건까지는 ms 단위라 충분하다.
   - `GET /api/glossary` → `[{term, gloss, count, lastSeen}]`. 용어는 소문자·공백 정리로 묶고, 풀이는 가장 최근 것. count 내림차순.
   - `GET /api/stats` → `{total, byKind:[{kind, count}], questions:[{question, count, lastSeen, kind}]}`. 질문은 큰따옴표 안 인용문을 `"…"` 로 접어 묶는다 — 라이브 카드에서 온 질문("방금 이 에러 뭐야? "…"")이 매번 달라도 같은 질문으로 센다. 상위 10개.
4. **화면은 같은 페이지의 "복습" 뷰.** 왼쪽 상단 버튼으로 대화 뷰와 전환. 용어 카드, 자주 묻는 질문 순위(누르면 입력창에 채움, 자동 전송 없음), 질문 종류 막대. 세션을 고르면 대화 뷰로 돌아간다.
5. 추출 규칙: 용어는 `(` 바로 앞에 붙은 24자 이하 토큰(한글·영문·숫자·`.-_/`), 풀이는 괄호 안 2~80자, 한글 포함, 괄호 중첩 없음. 용어가 `요·다·죠` 로 끝나거나 풀이가 `요·다·죠` 로 끝나면 문장 부연으로 보고 버린다.

## Consequences

- (+) 질문을 할수록 용어집이 저절로 자란다. 도슨트 프롬프트를 바꾸지 않는다.
- (+) 저장 시 한 번만 판정하므로 복습 화면은 Jev 없이도 즉시 뜬다.
- (−) 규칙 추출은 "했어요(그래서…)" 같은 부연을 가끔 용어로 오인한다. Jev 키가 있으면 걸러진다.
- (−) 질문 묶기는 인용문 접기뿐이라 표현이 조금만 달라도 다른 질문으로 센다. 상위 10개 순위 용도로는 충분.
- 6번 "미리 알려주기"는 이 집계(자주 묻는 kind, 용어 등장 빈도) 위에서 설계한다.
- 영향 범위: `app/review.mjs`(신규), `app/server.mjs`, `app/index.html`, `docs/architecture.md`
