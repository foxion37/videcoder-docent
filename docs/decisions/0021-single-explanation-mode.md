# 0021 — 설명 모드는 설정 하나로 통일, 이해 상태 화면 제거

Date: 2026-09-23
Status: Accepted. ADR 0014·0019의 "이번 질문" 설명 깊이/모드 선택과 ADR 0014·0020의 이해 상태 편집 화면을 대체한다.

## Context

설정에 "설명 모드 설정"(프로필에 저장)과 "이번 질문 모드"(저장 안 됨, 세션을 바꿀 때까지 이후 모든 질문에 적용)가 함께 있었다. 이름과 달리 한 질문에만 쓰이지 않았고, 둘의 차이를 사용자가 알 수 없었다.

## Decision

1. "이번 질문 모드"를 설정과 작은 창에서 없앤다. 수동 질문은 프로필의 설명 모드 설정만 따른다.
2. 설명 모드 설정 안의 이름은 "기본값"과 "영역별 설정"으로 통일한다. 둘이 다르면 더 어려운 모드를 쓴다(ADR 0019).
3. 요청 하나에만 다른 모드를 쓰는 경로는 입력창의 "설명 방식" 메뉴(EASY)와 자동 설명(EASY)뿐이다. 답변 아래에는 적용 근거를 "기본값", "영역별 설정", "설명 방식 메뉴"로 표시한다.
4. 서버의 `/api/ask` `difficulty` 입력은 설명 방식 메뉴와 자동 설명이 쓰므로 유지한다.
5. 배운 내용 다시보기에서 "이해 상태 기록"을 없앤다. 개념별 상태와 남은 의문은 설명 전략을 고르는 내부 기억으로 계속 저장하지만 화면에는 두지 않는다. `GET /api/learning`, `PATCH /api/learning/:id`는 API로 남긴다.

## Consequences

- 설명 모드를 바꾸려면 설정에서 저장해야 한다. 잠깐만 다른 모드로 보는 기능은 설명 방식 메뉴의 EASY 재설명뿐이다.
- 사용자가 "이해함"으로 표시하는 경로가 화면에서 사라진다. 상태는 새 질문의 의문으로만 갱신된다.
- 영향 범위: `app/index.html`, `README.md`, `docs/architecture.md`
