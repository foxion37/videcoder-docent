# 0026 — 작은 창은 작업 내용과 대화의 미니 버전

Date: 2026-09-24
Status: Accepted. ADR 0014의 작은 창 구성(최신 답 하나, 본문 대화·배운 내용 다시보기 버튼)을 대체한다.

## Context

작은 창에는 최신 답 하나와 입력창, "본문 대화"·"배운 내용 다시보기" 버튼이 있었다. 카드별 대화(ADR 0022) 이후 사용자는 작업 내용을 보며 그 카드에 대해 묻는다. 작은 창에서 카드를 고를 수 없어 결국 본문으로 돌아가야 했다.

## Decision

1. 작은 창은 새 공간이 아니라 본문의 미니 버전이다. 작업 내용(미니 카드 목록: 카테고리 칩, 짧은 제목, 즐겨찾기)과 선택한 카드의 대화, 입력창만 둔다.
2. 비중은 작업 내용:대화 약 35:65. 폭 720px 미만은 위/아래, 이상은 좌/우.
3. 카드를 누르면 본문과 같은 `openThread`로 대화를 연다. 질문은 본문과 같은 스레드에 쌓인다.
4. "본문 대화", "배운 내용 다시보기" 버튼과 안내 문구를 없앤다. 원문 보기와 다시보기는 본문에서 연다.
5. ADR 0014 계약은 유지한다: 별도 SSE·모델 호출 없음, 자동 설명이 포커스를 빼앗지 않음, 부모 탭과 함께 닫힘, 미지원이면 사유만 안내.
6. 카드 목록과 대화는 바뀐 것이 있을 때만(카드·스레드·기록 수·진행 상태 키) 다시 그린다.

## Consequences

- 작은 창만으로 카드를 고르고 이어 물을 수 있다.
- 기본 창 크기(420×560)에서는 카드 목록이 짧게 보인다. 사용자가 창을 키우면 좌우 배치가 된다.
- 영향 범위: `app/index.html`, `README.md`, `docs/architecture.md`
