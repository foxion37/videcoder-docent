# 0025 — 카드 제목은 짧은 요약, 출력 내용 보기 강조

Date: 2026-09-24
Status: Accepted. ADR 0018 §1의 "카드 제목 = 답의 결론 문장"을 대체한다.

## Context

작업 내용 카드 제목이 결론 문장이라 길고, 카드만으로 무슨 일인지 알기 어려웠다. 반면 AI가 실제로 출력한 원문은 중요한데 "AI 원문 보기"라는 흐린 글자로 숨어 있었다.

## Decision

1. 학습 분류 출력에 `title`을 추가한다. focus(카드 내용)가 있을 때 세션 제목처럼 20자 안팎 명사형 요약이다. 추가 모델 호출은 없다. 답에 `title`로 저장한다.
2. 카드 제목은 `title`, 없으면 예전처럼 결론 문장. `title`이 있으면 결론 문장을 요약의 첫 문장으로 옮긴다(최대 3문장 유지).
3. "AI 원문 보기"를 "출력 내용 보기"로 바꾼다. 카드가 가리키는 것은 AI가 그 시점에 출력한 메시지다. 포인트 컬러 알약 버튼으로 표시하고, 펼친 원문은 흰 상자에 둔다.

## Consequences

- 설명이 준비되기 전 카드와 예전 답은 여전히 원문 첫 줄이나 결론 문장을 제목으로 쓴다.
- 영향 범위: `app/learning.mjs`, `app/index.html`, `app/markdown.css`, `tests/learning.test.mjs`
