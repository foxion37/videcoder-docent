# 0010 — 미리 알려주기: 공짜 힌트 먼저, 자동 설명은 켜는 사람만

Date: 2026-09-22
Status: Accepted (2026-09-22, 사용자가 2단계까지 승인)

## Context

ADR 0006 은 라이브 카드를 띄우되 설명은 사용자가 버튼을 눌러야 오게 했다(질문당 30초, 모델 호출 비용). 이제 재료가 둘 생겼다: 라이브 이벤트 흐름(0006)과 문답 기억 집계(0008 — 용어집, 자주 묻는 kind). "곧 물어볼 것"을 먼저 보여 주려면 이 둘을 잇는다. 단, 이벤트마다 도슨트를 자동으로 부르면 세션 하나에 수십 번 호출이 생긴다.

## Decision

두 단계로 나눈다. 1단계는 모델 호출이 없어 항상 켠다. 2단계는 비용이 들어 사용자가 켠다.

### 1단계 — 공짜 힌트 (항상)

1. **용어 힌트.** 라이브 카드 본문에 용어집(`GET /api/glossary`)에 있는 용어가 나오면 카드 아래에 `용어 — 풀이` 한 줄씩 붙인다(최대 3개). 페이지가 세션을 열 때 용어집을 한 번 받아 두고 카드마다 문자열 검색. 서버 호출 없음.
2. **같은 일은 다시 안 묻는다.** 카드의 "설명 듣기"를 누르기 전에, 이 세션 기록(`GET /api/history?id=`)에 같은 질문(인용문까지 포함한 전체, 공백만 정리)이 있으면 그 답을 바로 펼친다. 버튼 문구는 "전에 들은 설명 보기". 통계용 접기(0008)는 쓰지 않는다 — 다른 에러를 같은 질문으로 뭉개면 안 된다. 새로 묻고 싶으면 입력창으로.
3. **자주 묻는 것 칩.** 입력창 위 고정 칩 6개 뒤에 `GET /api/stats` 의 상위 질문 중 고정 칩에 없는 것을 최대 3개 더 붙인다.

### 2단계 — 자동 설명 (끄고 시작, 헤더 토글)

4. 토글이 켜진 세션에서 `error` 와 `question` 이벤트가 오면 페이지가 `POST /api/ask {auto: true}` 로 도슨트를 미리 부르고, 답을 카드에 접힌 상태로 붙인다("미리 풀어 놨어요 ▸"). `assistant` 는 Jev `blocked` 판정일 때만. 서버가 아니라 페이지가 부르는 이유: 페이지가 닫혀 있으면 보여 줄 곳이 없고, 큐·상한을 브라우저 안에서 세는 게 단순하다.
5. 제한: 페이지 안에서 한 번에 하나(직렬), 10분에 5개까지, 같은 질문은 건너뛴다. 넘치면 카드에 버튼만 남긴다(지금과 같음). 세션을 바꾸면 큐를 비운다.
6. 토글 상태는 브라우저 `localStorage["docent.auto"]`. 서버는 `auto: true` 를 레코드에 남기고, 자주 묻는 것 순위에서는 뺀다(사용자가 물은 게 아니므로). 용어집과 kind 분포에는 들어간다.

### 안 하는 것

- "곧 물어볼 것" 예측 모델. 자주 묻는 kind 로 카드 순서를 바꾸는 정도는 근거가 약해 만들지 않는다. 기록이 수백 건 쌓인 뒤 다시 본다.
- 2단계를 기본 켬으로 두는 것. 비용이 사용자 몫이다.

## Consequences

- (+) 1단계는 오늘 붙일 수 있고 비용이 0. 용어 힌트는 질문할수록 좋아진다.
- (+) 2단계를 켠 사람은 에러가 나는 순간 설명이 이미 와 있다.
- (−) 2단계는 세션이 시끄러우면 10분에 5회 상한에 걸려 일부만 미리 온다. 상한은 관찰 뒤 조정.
- (−) 1단계 2번은 "같은 에러가 또 났다"를 "이미 설명함"으로 뭉갠다. 답에 "전에 들은 설명" 표시를 붙여 구분한다.
- 영향 범위(1단계): `app/index.html`. (2단계): `app/server.mjs`, `app/live.mjs`, `app/store.mjs`, `app/index.html`
