# 0019 — 노란 포인트 컬러, 설정 정리, 설명 모드 적용 규칙

Date: 2026-09-23
Status: Accepted. ADR 0014의 "이번 질문 설정 > 일치하는 분야 설정 > 프로필 기본값" 우선순위를 대체한다.

## Context

포인트 컬러가 파란색이라 노란 도슨트 로고와 맞지 않았다. 설정 창은 영어 제목과 긴 안내문이 많아 필요한 항목을 찾기 어려웠다. 사용자는 "깊이"를 "모드"로 부르고, 기본 모드와 영역별 모드가 다르면 더 어려운 쪽으로 설명하기를 원했다.

## Decision

1. **포인트 컬러는 로고 노랑.** 채움·테두리는 `--accent`(노랑), 흰 바탕 위 글자·초점선은 읽을 수 있는 `--accent-ink`(어두운 금색)를 쓴다. 노랑 위 글자는 어두운 색이다.
2. **왼쪽 위에 로고**, 세션 수와 아이콘 버튼은 오른쪽.
3. **설정 창.** 제목은 "설정". 학습 프로필 아래 도슨트 모델, 설명 모드 설정, 화면과 질문, 자동 설명을 같은 모양의 카드로 둔다. 설명 모드 설정은 접히는 카드이며 노란 테두리로 강조한다. 안내는 짧은 "~함" 체, 엠대시와 가운데 점을 쓰지 않는다. 가격은 "100만 토큰 당 예상 비용(USD), 실제 비용과 다를 수 있음" 한 줄만 둔다.
4. **설명 모드 적용.** 이번 질문 모드가 있으면 그것을 쓴다. 없으면 기본 설명 모드와 질문 영역에 맞는 상세 설명 모드 중 더 어려운 모드를 쓴다. 상세 모드가 기본보다 쉬우면 기본 모드를 쓴다.

## Consequences

- 상세 모드를 기본보다 쉽게 설정해도 효과가 없다. 쉬운 설명이 필요하면 기본 모드를 낮추거나 이번 질문 모드를 쓴다.
