# 0001 — 문서·설계 우선, 스택 보류

Date: 2026-09-21
Status: Accepted

## Context

videcoder-docent는 바이브코더 세션에 붙는 설명 전용 서브에이전트다. 어느 호스트 에이전트에 붙을지(omp, Claude Code, Hermes)가 정해지지 않았고, 호스트에 따라 언어·전사 접근 방식이 완전히 달라진다.

## Decision

호스트가 정해질 때까지 구현 코드를 만들지 않는다. 저장소에는 개념·범위·열린 질문·ADR만 둔다. 스택은 호스트 결정 ADR과 같이 정한다.

## Consequences

- (+) 잘못된 스택으로 시작해 버리는 비용 회피
- (+) 호스트가 무엇이든 재사용되는 부분(질문 5종, 답변 원칙, 완료 기준)이 먼저 고정됨
- (−) 프로토타입으로 감을 잡는 시점이 늦어짐. 열린 질문 1번이 답해지면 즉시 해제.
- 영향 범위: `AGENTS.md`, `docs/`
