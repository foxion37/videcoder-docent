# 0012 — 새로고침 버튼과 최근 이벤트 재생

Date: 2026-09-22
Status: Accepted. ADR 0006 의 "과거는 안 보냄"을 일부 바꾼다.

## Context

ADR 0006 은 세션을 고른 뒤 생기는 이벤트만 보낸다. 실제로 써 보니 (1) 이미 한참 돌던 세션을 열면 화면이 비어 있어 "살아 있는 건지" 알 수 없고, (2) 세션 목록은 15초마다 저절로 바뀌지만 열어 둔 세션의 이전 문답·연결 상태는 손으로 되살릴 방법이 없다. 사용자 요청: "실시간이 아니면 새로고침이 필요하다".

## Decision

1. **구독 시작 때 꼬리를 재생한다.** `app/live.mjs` 가 첫 stat 에서 파일 끝 512KB 를 읽어 이벤트를 뽑고, 마지막 5개를 `past: true` 로 먼저 보낸 뒤 "지켜보고 있어요"를 보낸다. 어시스턴트 텍스트는 새 이벤트와 같은 Jev/길이 규칙으로 거른다. 페이지는 past 카드를 흐리게 그리고 "조금 전"을 붙이며, 자동 설명(ADR 0010)은 past 에 대해 돌리지 않는다.
2. **헤더에 "새로고침".** 세션 목록을 다시 받고, 열린 세션이 있으면 이전 문답을 다시 그리고 SSE 를 다시 연다(그러면 1번 재생도 다시 온다). 옆에 "갱신: N분 전"을 보여 준다.
3. 폴링 주기(1초)·목록 갱신 주기(15초)는 그대로.

## Consequences

- (+) 세션을 열면 방금 무슨 일이 있었는지 바로 보인다.
- (+) 연결이 이상하면 버튼 하나로 복구.
- (−) 재생 5개는 "최근 512KB 안"이라 조용한 세션에선 오래된 것이 뜰 수 있다. "조금 전" 표시로 구분.
- 영향 범위: `app/live.mjs`, `app/index.html`
