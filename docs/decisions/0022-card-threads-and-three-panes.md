# 0022 — 카드별 대화, 즐겨찾기, 세 공간 화면

Date: 2026-09-24
Status: Accepted. ADR 0017 §1·§3의 "대화 하나에 이어 묻기"를 카드별 스레드로 대체한다.

## Context

작업 흐름의 모든 카드가 대화 하나를 공유해서, 카드마다 무엇을 물었고 무엇을 답했는지 따로 보기 어려웠다. 중요한 대화를 골라 둘 방법도 없었다. 카테고리(질문, 작업 결과, 계획)는 글자로만 구분됐고, 세션 목록, 작업 흐름, 대화 세 영역이 같은 흰 바탕에 선 하나로만 나뉘었다.

## Decision

1. **카드별 대화 스레드.** 스레드 키는 질문 대상 내용이다(공백 정리). 카드를 누르면 그 카드의 스레드가 열리고, 준비된 쉬운 설명이 첫 답으로 보인다. 카드에 묶이지 않은 문답은 "세션 전체 대화"에 모인다. 서버는 설명 생성 때 같은 스레드의 최근 수동 문답만 이어 묻기 맥락으로 쓴다. 저장 형식은 바꾸지 않는다(문답의 `focus`로 구분).
2. **즐겨찾기(별).** 카드와 대화 머리에 별 버튼을 둔다. `learning.json`의 `favorites`에 프로필, 세션, 스레드 내용으로 저장한다. 작업 내용 제목 옆 별로 즐겨찾기한 카드만 볼 수 있다. 나중에 우선순위나 기억을 만들 때 이 표시를 재료로 쓴다.
3. **카테고리 색과 아이콘.** 질문(주황, 물음표), 작업 결과(초록, 체크), 계획(남색, 목록). 굵은 왼쪽 선 대신 작은 칩으로 표시한다.
4. **작업 흐름 → 작업 내용**, 최신 카드가 맨 위.
5. **세 공간과 펼침.** 세션 사이드바는 접을 수 있다(아이콘 줄로 축소, 기기에 기억). 세션을 고르면 작업 내용이 펼쳐지고, 카드를 누르면 대화가 옆에서 밀려 들어온다. 움직임 줄이기 설정에서는 애니메이션을 끈다.
6. **공간 구분.** 세션은 흰 바탕과 그림자, 작업 내용은 옅은 회색 바탕과 2px 경계선, 대화는 흰 바탕.
7. 답변의 "질문하기" 버튼은 없앤다. 답은 이미 그 스레드 안에 있다.

## Consequences

- 카드 내용이 바뀌면(원문 수정) 다른 스레드가 된다. 설명 방식 메뉴로 세션 전체 대화에서 다시 설명하면 그 답은 세션 전체 대화에 남는다.
- 새로고침하면 열려 있던 스레드는 닫힌다.
