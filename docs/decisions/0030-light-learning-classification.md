# 0030 — 전사 없이 가볍게 하는 학습 분류

Date: 2026-09-25
Status: Accepted. ADR 0014 "분류와 설명"의 분류 입력을 바꾼다. 분류 → 설명 순서와 설명 전 깊이 결정은 유지한다.

## Context

학습 분류 호출도 설명 호출처럼 전사 전체를 읽어서 대기 시간의 절반 가까이를 차지했다. 분류 결과(질문 종류, 개념, 분야, 핵심 단어, 카드 제목)는 대부분 질문과 질문 대상, 직전 대화, 기억 후보로 판단할 수 있다.

## Decision

1. 분류 호출은 전사를 받지 않는다. 입력은 질문, 질문 대상, 같은 스레드의 최근 문답 요약, 기억 후보(24,000자 예산), 사용자가 보고 있는 사건 카드 목록이다. thinking은 끄고 읽기 도구도 주지 않는다.
2. 분류는 질문이 가리키는 사건 카드도 고른다. 현재 스레드와 다른 카드면 답 아래에 옮기기를 제안한다(ADR 0028 §4). 목록 밖 카드는 만들지 않는다.
3. 분류 실패 시 처리(모델 미지정이면 경고와 함께 기본 깊이로 계속, 지정 모델이면 오류)는 그대로 둔다.

## Consequences

- 분류가 몇 초 안에 끝나고 설명이 곧바로 시작된다.
- 전사에만 있는 단서로는 분류하지 못한다. 그런 경우는 unknown으로 남으며, 설명은 전사를 그대로 본다.
