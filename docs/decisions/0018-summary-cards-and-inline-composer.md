# 0018 — 요약 카드, 카드 전체 클릭, 입력창 안 도구

Date: 2026-09-23
Status: Accepted. ADR 0017 §1의 "항목을 누르면 설명이 대화에 펼쳐진다"와 항목 행동 버튼, §5의 "입력창 옆 설명 방식" 배치를 대체한다.

## Context

작업 흐름 카드는 AI 원문 첫 줄을 제목으로 쓰고 "쉽게 설명해줘"·"이 내용으로 질문하기" 두 버튼을 달았다. 제목이 원문이라 읽기 어려웠고, 준비된 설명도 누르기 전에는 보이지 않았다. 버튼 둘은 결국 "이 항목에 대해 이야기하기"라는 한 가지 행동이었다. 입력창 위의 설명 방식 줄과 입력창 옆 "묻기" 버튼은 대화 영역의 세로·가로 공간을 차지했다. 세션 목록은 최대 200개를 한 번에 그렸다. 사용자가 여섯 가지 수정을 요청했다.

## Decision

1. **카드 제목은 한 줄 요약.** 설명이 준비되면 답의 결론(headline)을 제목으로 쓰고 한 줄에서 말줄임한다. 준비 전에는 원문 첫 문장을 한 줄로 보여 준다. 질문 대상 표시도 같은 제목을 쓴다.
2. **제목 아래 3문장 이내 요약.** 준비된 답의 핵심 설명에서 코드 블록·표를 빼고 앞 3문장을 평문으로 보여 준다. 새 모델 호출이나 요청문 변경은 없다(요청문이 바뀌면 저장된 자동 설명과 연결이 끊긴다). 설명이 없으면 원문을 요약처럼 보여 주지 않고 상태 안내만 둔다(ADR 0015 §2).
3. **카드 전체가 버튼 하나, 누르면 질문 대상만 정한다.** 질문 대상으로 고르고 입력창에 초점을 옮긴다. 모델을 부르지 않고 대화에 설명을 펼치지도 않는다. 설명을 원하면 입력하거나 설명 방식 메뉴를 쓴다. "AI 원문 보기" 펼침은 카드 위에서 따로 동작한다.
4. **상단 버튼은 같은 알약 모양.** 작은 창·새로고침(과 배운 내용 다시보기·테마)은 한 스타일을 쓴다.
5. **입력창 안에 도구.** 보내기는 위쪽 화살표 원형 버튼, 그 왼쪽에 설명 방식 메뉴를 둔다. 입력창 위 별도 줄을 없애 대화 영역을 넓힌다. PiP도 같은 배치다.
6. **세션은 최근 10개부터.** 나머지는 "더 보기"로 10개씩 연다. 검색하면 다시 10개부터다. 열린 세션은 한도 밖이어도 목록에 남긴다.

## Consequences

- 카드만 훑어도 무슨 일인지 알 수 있다. 요약은 저장된 답에서 만들기 때문에 과거 기록에도 바로 적용된다.
- 카드를 눌러도 비용·대기가 없고 바로 질문할 수 있다. 준비된 설명의 전문·원문 보기 버튼은 카드에서 대화로 펼쳐지지 않으므로, 전문은 질문하거나 설명 방식으로 다시 받아야 한다.
- 문장 나누기는 마침표·물음표·느낌표 기준이라 목록 위주 설명은 항목 단위로 잘린다.
