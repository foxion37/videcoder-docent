# 0031 — 미리 설명은 상시 서버가 한다

Date: 2026-09-25
Status: Accepted. ADR 0010 §4·§6(페이지가 자동 설명을 부르고 켜기 상태를 브라우저에 저장)과 ADR 0015 §3의 실행 주체를 대체한다. 상한·직렬 처리·자동 질문을 학습 반복에서 빼는 규칙은 유지한다.

## Context

미리 설명은 탭이 열려 있을 때만 준비됐다. 탭을 닫은 동안 생긴 사건 카드는 사용자가 누를 때 30~80초를 기다려야 했다. ADR 0010이 페이지를 실행 주체로 정한 이유는 "페이지가 닫혀 있으면 보여 줄 곳이 없다"였다. 지금은 docent가 상시 실행되고 답이 프로필별로 저장되므로 그 전제가 바뀌었다.

속도를 위해 GitHub·Supabase 같은 클라우드 실행도 검토했지만 채택하지 않았다. 대기 시간의 원인은 계산 자원이 아니라 모델 왕복이다. 전사가 컴퓨터를 떠나면 ADR 0005·0011과 충돌하고, omp 로그인 대신 API 키를 다뤄야 한다.

## Decision

1. 프로필이 세션을 열면(라이브 구독) 서버가 그 프로필·세션을 12시간 동안 지켜본다. 탭을 닫아도 이어진다.
2. 선별된 새 사건마다 서버가 EASY 미리 설명 작업을 만든다. requestId는 프로필·세션·질문 대상으로 정해지므로 브라우저가 같은 요청으로 붙거나 저장된 답을 받는다.
3. 미리 설명 켜기/끄기는 프로필 설정이다(기본 켬). 상한은 프로필 전체 기준 10분에 5개다. 처리는 프로필마다 한 번에 하나씩이며, 수동 질문이 진행 중이거나 대기 중이면 기다린다.
4. 과거 재생 사건은 미리 설명하지 않는다.

## Consequences

- 탭을 다시 열면 그동안의 카드 설명이 이미 준비되어 있다.
- 사용자가 보지 않는 동안에도 모델 비용이 생긴다. 12시간 창과 상한으로 제한한다.
- 원격(peers) 세션도 같은 규칙을 따르며, 전사는 질문할 때만 가져온다.
- 영향 범위: `app/prefetch.mjs`(신규), `app/live.mjs`, `app/server.mjs`, `app/learning.mjs`(프로필 설정), `app/index.html`
