# 0032 — 학습 분류는 답 뒤에, Codex·Gemini·pi 세션 추가

Date: 2026-09-25
Status: Accepted. ADR 0014 "분류와 설명"의 순서(분류 → 설명)와 ADR 0030 §1의 분류 시점을 대체한다. 분야별 깊이 설정이 있을 때만 설명 전에 분야를 판정한다. ADR 0016의 "분류와 설명은 같은 모델"은 유지하며, 선택한 모델의 분류 실패는 답을 막지 않는다.

## Context

ADR 0030 이후에도 학습 분류가 설명 시작 전 9.6~12.7초를 차지했다(opus 기본 모델). 같은 모델에 빈 질문만 보냈을 때는 3.9초였다. 그러니 대기 시간 대부분은 분류기가 개념·핵심 단어·뜻풀이·전략·카드 제목을 JSON으로 길게 쓰는 시간이다. 설명 전에 꼭 필요한 것은 두 가지뿐이다. 분야별 깊이 설정이 있을 때의 분야, 그리고 관련 학습 기억이다. 사용자는 분류를 답 뒤로 옮기는 안을 골랐다.

같은 결정에서 Codex CLI·Gemini CLI·pi 세션을 읽도록 추가하고, Claude Code 서브에이전트 진행이 전사 캐시에 반영되게 하기로 했다.

## Decision

1. **설명이 먼저다.** 깊이는 이번 질문 선택 > 분야별 판정(분야별 설정이 있는 프로필만, 짧은 분야 전용 호출) > 프로필 기본값이다. 학습 기억은 분류기가 골라 주지 않고, 현재 범위의 기억 후보 요약(개념·상태·남은 의문·지난 전략·지난 질문, 6,000자)을 설명 호출에 넣는다. 설명 모델이 관련된 것만 참고한다.
2. **답을 먼저 저장하고 요청을 완료한다.** 문답은 `learning.classification: "pending"`으로 저장한다. 같은 requestId 재전송은 이 답을 돌려준다.
3. **분류는 답 뒤에서 돈다.** 입력은 질문, 질문 대상, 최근 대화, 방금 한 답(결론·핵심 설명), 카드 목록, 기억 후보다. 결과로 개념별 설명 이력·반복 판정·핵심 단어·카드 제목·카드 제안을 같은 문답에 붙인다. 분류하는 사이 기억이 바뀌었으면 그 개념은 새 기억으로 둔다. 실패하면 개념을 추측하지 않고 `unknown`과 경고를 남긴다. 다른 모델로 바꾸지 않는다.
4. **보고 있는 화면에 알린다.** 분류가 끝나면 그 세션을 보고 있는 같은 프로필의 라이브 연결로 `{kind: "record", recordId, thread, answer}`를 보낸다. 화면은 카드 제목·용어·카드 제안을 갱신한다.
5. **Claude Code 전사 캐시** 기준에 옆 폴더 서브에이전트 파일의 이름·크기·수정 시각을 더한다. 파일 내용은 읽지 않는다.
6. **세션 제공자 추가.** Codex CLI(`~/.codex/sessions/YYYY/MM/DD/rollout-*.jsonl`), Gemini CLI(`~/.gemini/tmp/<project>/chats/session-*.jsonl`, 작업 폴더는 `.project_root`), pi(`~/.pi/agent/sessions/*/*.jsonl`, omp 형식 + 제목·모델 항목 차이만 변환). 목록은 폴더 깊이와 파일 이름 규칙으로 찾는다. 파일 머리는 파일이 바뀌었을 때만 다시 읽는다.

## Consequences

- 실측으로 첫 글자까지 7.9초, 답 완료 16초, 분류는 그 뒤 5.5초에 붙었다(같은 세션, opus 기본 모델). 이전 흐름에서는 첫 글자까지 약 21초였다.
- 카드 제목·카드 제안·용어 링크가 답보다 몇 초 늦게 붙는다.
- 반복 의문의 설명 전략은 분류기의 판정이 아니라 기억 후보 요약과 스레드 대화를 보고 설명 모델이 고른다. 저장되는 반복 판정은 분류 결과를 따른다.
- Codex의 서브에이전트 메시지는 암호화되어 있어 한 줄 도구 호출로만 보인다. Codex·Gemini·pi는 대부분 구조화된 질문 도구가 없어서, 일반 문장의 질문·결과·계획 카드는 Jev 판정에 의존한다(Codex의 `request_user_input_async`, Gemini의 `ask_user`는 질문 카드가 된다). Gemini는 파일 전체를 다시 쓰는 경우가 있어 라이브 이벤트가 중복되거나 되돌려진 메시지가 남을 수 있다.
- 영향 범위: `app/learning.mjs`, `app/server.mjs`, `app/prefetch.mjs`, `app/index.html`, `scripts/transcript-{claude,codex,gemini,pi}.mjs`, `tests/`
