# v0.1 범위

## 포함

- 질문 5종에 대한 답변 (@docs/concept.md 핵심 동작 표)
- 입력 소스 1개: 세션 전사. 나머지는 이후 버전.
- 출력: 텍스트만.
- 호스트 1개: 처음 붙일 메인 에이전트 하나만 지원. 어느 것인지는 미정.

## 제외

- 코드 수정·실행·커밋
- 음성 입출력
- 여러 세션 동시 추적
- 사용자별 학습·기억
- 자체 UI. 호스트 에이전트의 서브에이전트/도구 형태로만 존재.

## 완료 기준

- 실제 바이브코더 세션 전사 3개로 질문 5종을 돌렸을 때, 답이 틀리지 않고 개발 용어 없이 읽힌다.
- 도슨트가 코드를 건드리려 한 사례 0건.
